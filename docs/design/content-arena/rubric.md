# Rubric (judges only; candidates never saw this). Score each 1-5.

1. **Something worth showing.** After using it, a couple has clearly more to show a partner, a friend or a group chat than the baseline's five highlights and one poster: more good moments and/or more shareable artifacts. A stranger would smile at what gets shared.
2. **Still simple.** The main path stays short and calm, one primary action per screen; extra content is findable but never in the way; no density creep, no dashboard.
3. **Honest and specific.** Every item is a real number/date/quote, true to the core's code, with a one-sentence "how we know"; no scores, decimals, verdict labels or feelings stated as facts; no contradictions; nothing embarrassing is forced into what gets shared.
4. **Decision quality.** The keep/move/add/cut table covers everything in the JSON with defensible reasons; cuts are as considered as additions; the structure follows from the decisions.
5. **Consistency and craft.** New screens look and behave like the existing ones (same type scale, spacing, components, motion); 390 px clean; keyboard and reduced motion work.
6. **Portability.** Same module boundaries (copy in pure modules, DOM in app code), CSP-safe, small enough to merge into the real app.
